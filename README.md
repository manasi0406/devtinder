# DevTinder

A full-stack web application inspired by Tinder, built to help users discover profiles and connect through connection requests.

## Features
- User signup and login
- JWT-based authentication
- Profile viewing and editing
- Discover other users
- Send and manage connection requests
- Protected APIs with authentication and authorization

## Tech Stack
- **Frontend:** React.js, Redux, React Router, Tailwind CSS / DaisyUI
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## About
Built as a learning project to understand full-stack development, REST APIs, authentication, authorization, and database operations.
